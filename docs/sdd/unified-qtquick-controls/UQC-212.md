  with HnAvatar and elided account names, fallback avatar, bounded popup,
  visible chevron and keyboard focus border. Select/authenticate by username.
- G01: bidirectional cycle account selector/manual username → password → reveal
  → login → session → keyboard layout → reboot → poweroff → first available
  input. Skip hidden/disabled controls, including compact-mode power actions.
  Preserve initial password focus and restoration after account/session selection.

  feedback. Document and verify selected-style password background/rendered
  states; preserve inherited background unless evidence establishes a defect.
- G06: transparent enabled idle power backgrounds, retained borders/feedback,
  unchanged reboot glyph and poweroff glyph at 1.25 times original size.

## Implementation and local verification — 2026-09-15

Local verification complete; publication and the manual gate are tracked in the
umbrella ledger. The account selector now composes HnIconComboBox/HnAvatar with
runtime selected-style ItemDelegate rows. Its 48-pixel control height accommodates
the existing 22.5-point centered name; the portrait remains 132 pixels. Shared
popup geometry and hover suppression are retained. A local cycle resolver skips
unavailable controls in both directions. Reveal owns a hold state, ignores key
repeat transitions and remasks on cancellation/lifecycle changes. Footer colors
are semantic; enabled idle power fills are transparent and poweroff is 1.25×.

Confirmed before changing login QML: Backtab from password skips the account
selector. Basic Space press/release and focus loss pass; the narrower repeat-release
regression fails (Password echo mode while Space is still held). This is evidence
of a repeat-transition defect, not proof of the entire reported physical-keyboard
failure. The human G02 check remains necessary. Baseline logs are retained in
umbrella `.cache/uqc212/uqc212-baseline.log` and `uqc212-reveal-baseline.log`.

Password background is intentionally inherited. HoloNight TextField uses
ControlPalette Text/Base roles, selected active/inactive/disabled group and its
semantic surface; Fusion TextField uses palette text/highlight and its
TextFieldBackground. Offscreen rendered samples at both DPRs show HoloNight
enabled fill #131a24/text #e7edf5, and Fusion enabled white/black. Focus preserves
the fill. Disabled HoloNight background has inherited ~0.5 opacity; Fusion uses
#efefef fill/#bebebe text. These samples use the isolated test palettes, not a claim
about every platform-theme configuration. Runtime tests assert palette sources,
selection color and successful rendered idle/focus/disabled captures. No concrete
background defect was demonstrated.
