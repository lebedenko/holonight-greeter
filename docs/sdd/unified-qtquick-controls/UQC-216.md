## Investigation result — 2026-09-15

**G07 is not reproduced by the automated production fixture. No production QML
repair is justified.** The package takes the planned bounded-diagnostics path.
The existing software suite is retained; `task caret-graphics` runs the same
production QML/fake services on a private headless Sway output (2560×1600, scale 1),
OpenGL/RHI and the staged HoloNight platform theme. No desktop input is automated.
The fixture asserts the backend and loaded platform theme, captures full windows
before toggling visibility, and compares pixels around the mapped native cursor.
Blink timing is restored by an RAII guard after each test. Font, padding, bounds,
clip rectangles, ancestor scales, focus and actual DPR are logged without text.

Both styles and DPRs show caret pixels for initial empty, populated, cleared and
refocused/remasked production fields, and none without field focus. Normal and
compact transforms are covered. Production response dimensions are 420×57, native
empty cursor `(54,17,1,23)` with the current font. No clipping ancestor is observed.
Representative graphics empty counts are 29 pixels at panel scale 1.25/DPR 1 and
72 at panel scale 1.25/DPR 1.25. The full-window initial HoloNight capture was also
visually inspected. These results do not establish the user's real-session result.

A minimal selected-style TextField is compared at the same scene position/scale,
with equivalent font/padding. Default-font, default-left-padding and unscaled
variants change one factor at a time. **A separate software-only diagnostic
failure is retained:** unscaled minimal field at `(223.656,340.718)`, DPR 1.25,
font 14.25 points and left padding 54 has zero on/off differences. Both styles
show it; the equivalent transformed production field and OpenGL variants pass.
Its assertion failure and images are in umbrella `.cache/uqc216/software-recheck.log`
and `software-samples/29-minimal-unscaled-{on,off}.png`. This variant is reported
as diagnostic data, not a passing acceptance assertion. It differs from G07's
reported scale-1 graphics failure; no provider repair is assigned from it.

The new opt-in `audit/caret-diagnostics.cpp` observer is for the isolated demo kit.
It leaves native blinking and input untouched, logs no entered text, records
geometry at 5 Hz for at most five minutes, and saves at most 120 small empty-field
crops in 12-frame bursts on state changes. Populated fields are never captured.
This permits manual comparison of the missing state without modifying production
composition, palette, native caret, navigation or reveal lifecycle.
